# Контекст проекта: Геопортал города Костанай

## Общая информация
Этот проект представляет собой интерактивную карту города Костанай (Казахстан). 
Цель: Визуализация социально-экономических данных, инфраструктуры и демографии.

## Технологический стек
- **Frontend:** HTML/JS
- **Картография:** MapLibre GL JS
- **Форматы данных:** - Основные слои: GeoJSON
    - Тяжелые слои (растры/векторы): PMTiles (используется для оптимизации загрузки)
- **Развертывание:** GitHub Pages / GitLab Pages

## Структура данных и слои
- В папке `/tiles` находятся файлы `.pmtiles` для отображения плотности населения и коммерческой активности.
- Статистические данные берутся из Бюро национальной статистики (БНС) РК.

## Географические ориентиры
- **Центр Костаная:** [63.6246, 53.2144] (Долгота, Широта)
- **Границы:** Фокусироваться на городской черте и ближайших агломерациях.

## Правила написания кода для Агента
1. **Стилизация:** При добавлении новых слоев используй стили, соответствующие общей дизайн-системе (например, синие иконки для образования, красные для медицины).
2. **Оптимизация:** При работе с большими массивами данных всегда предлагай использование PMTiles вместо прямого импорта тяжелых GeoJSON.
3. **Локализация:** Все подписи на карте и в балунах (popups) должны быть на русском языке (с возможностью расширения на казахский).
4. **Комментирование:** Обязательно комментируй логику добавления новых слоев в основном файле инициализации карты.
